## Reproduce the full nominal failure

Use the repository's pinned Windows Python environment and unchanged runtime. Run from the repository root and choose a fresh output directory; do not overwrite preserved evidence. A full mission is substantially longer than the isolated probes. These commands are documented for reproduction and were not rerun during final publication:

```powershell
.venv\Scripts\python.exe run_physics.py --scenario-file scenarios\uavx\nominal.json --output evidence\research-nominal-reproduction-01 --max-time 2700 --require-pass
.venv\Scripts\python.exe verify_physics.py evidence\research-nominal-reproduction-01 --source-root . --output evidence\research-nominal-reproduction-01-verification.json
```

With the recorded runtime/environment, the retained baseline fails the strict mission check; `--require-pass` is expected to return exit code 2. Inspect evidence validity separately from mission success. Cross-platform bitwise identity has not been established. A future fix should be compared with these preserved inputs and limits rather than replacing the failure record.

For the existing local run, the delivered timeline is generated by:

```powershell
.venv\Scripts\python.exe research\uavx-20261106\tools\summarize_integrated.py evidence\research-physics-nominal-20261106-01
```

The summarizer expects the independent verification JSON already saved in the research folder. It rewrites the derived summary and figure, not the original mission evidence. For separate experiment commands and their limits, use the [radio sensitivity](radio-sensitivity-01/README.md), [feedback study](radio-feedback-01/README.md) and [physics notes](physics-control-research.md).
